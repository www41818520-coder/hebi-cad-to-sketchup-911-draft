# HEBI CAD to SketchUp 911

An experimental, drawing-led architectural modeling Skill for Windows and SketchUp.

## Included

- Complete 911 Skill and downloadable ZIP package.
- English project overview, workflow diagram and captions for three historical development images.
- Human review or an optional independent agent, selected at intake without a fixed provider.
- Traceable evidence, versioned outputs, reusable components and simple material support.

## Validation boundary

69 automated regression tests passed, including an isolated archive extraction run.
Eight execution checks covered the suite and supporting entrypoints.
A new real-world CAD-to-SketchUp trial using this release has not yet been completed.
The showcased project used earlier workflow versions and project-specific scripts; it is not evidence of one-click 911 reproduction.

The implementation includes some Chinese examples and references. The public overview and diagram are in English; no modeling code was changed for this publication.

Download the package from the repository's `dist/` folder. Install its complete top-level Skill directory, not just `SKILL.md`.
